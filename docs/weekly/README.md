# Weekly notes (historical)

Notes, guides and write-ups produced while building Weeks 3-11. They are kept as a record of what was found and decided at the time (taxonomies, verdicts, the 10x plan, per-week guides).

**They describe the project before it was consolidated.** Paths inside them, such as `run_week11_eval.py` at the repo root, `documentation/...`, `rag.infra...` or absolute `file:///d:/...` links, refer to locations that have since moved. Use [`../legacy.md`](../legacy.md) to map an old path to its new home, and [`../features.md`](../features.md) for how each capability works today.

Numbers in these notes (for example a 70% hit rate) were measured on an earlier HR-policy corpus and Pinecone index and are not reproducible on the current insurance PDFs; the current evaluation results are on the Evaluation page.
